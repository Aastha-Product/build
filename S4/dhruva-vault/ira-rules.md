# Ira's rules for the triage system

1. Every verdict has a citation from the deck.
2. Where a criterion cannot be established, say INSUFFICIENT DATA. The score must reflect the absence.
3. Under Rs 20 per application.
4. The same application run twice moves by at most 1 point.
5. An application's result must not depend on where it sits in the batch.
6. The system recommends. A person decides.
