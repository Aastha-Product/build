# dhruva-vault: a starter notes vault

Open this folder in Obsidian (Open folder as vault). Each note is a plain text file written in markdown. Three notes are provided. You write two more before the next session:

1. `escalation-rules.md`: when the agent must hand an application to a human analyst, and what it should say.
2. `tone-guide.md`: how the agent should word a decline or a request for more information to a founder.

Rules for a good note: one topic, short, written so a stranger could act on it, and linked to related notes with [[double brackets]].
